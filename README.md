# Dead Day

A lightweight offline-first zombie survival text game built with Flutter and Dart.

> Project status: initial Flutter prototype under construction. The deterministic game engine is the source of truth; on-device AI will be an optional narrative layer, not a dependency for gameplay.

See `docs/GAME_DESIGN.md` for the planned seven-week scope. The Android/iOS runner directories are generated locally using `flutter create --platforms android,ios .` after cloning.
